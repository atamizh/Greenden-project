# Greenden-project
Greenden is a responsive plant and nature-themed website designed using *HTML and Tailwind CSS*. The project focuses on creating a clean, modern, and user-friendly interface for showcasing plants, products, and nature-related content.

✨ Features

* Clean and modern plant-themed design
* Fully responsive layout for *Mobile, Tablet, and Desktop*
* Styled using *Tailwind CSS*
* Attractive product and plant sections
* Responsive navigation bar
* Semantic HTML structure
* Lightweight and fast-loading design
* Flexible layouts using Tailwind's responsive utilities

🛠️ Technologies Used

* HTML5 – Website structure and content
* Tailwind CSS – Styling, layout, and responsive design

🎯 Project Purpose

This project was created to practice and improve my skills in *HTML, Tailwind CSS, responsive web design, layouts, and modern UI development.

Responsive Design
* Greenden is designed to provide a smooth user experience across different screen sizes:
* Mobile
* Tablet
* Desktop
